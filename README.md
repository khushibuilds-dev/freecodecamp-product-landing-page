# Fancy Kurti - Product Landing Page

A clean, modern, and responsive product landing page designed for **Fancy Kurti**, showcasing their Summer Collection of Floral Printed Cotton Co-ord Sets.

## Features
* **Fixed Navigation Bar:** Smooth scrolling links to Features, Product Tour, and Pricing sections.
* **Hero Section:** Attractive banner with an email subscription form.
* **Product Highlights:** Three-column card layout detailing quality, daily comfort, and versatility.
* **Embedded Product Video:** Integrated YouTube video tour of the collection.
* **Product Showcase Card:** Clean pricing card featuring product image, details, and a "Buy Now" button.
* **Mobile Responsive:** Adapts seamlessly to desktop, tablet, and mobile screens.

## Technologies Used
* **HTML5:** Semantic structure (header, nav, main, section, footer).
* **CSS3:** Flexbox layout, custom gradients, hover animations, and media queries.

## Project Structure
```text
├── index.html      # Main HTML document
├── styles.css      # Stylesheet for layout and design
└── README.md       # Project documentation
```

## How to Run
1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
